# Basemap assets — provenance and licenses

Vendored from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets)
so the self-hosted `pmtiles` basemap mode makes zero requests to any third party.

- `fonts/` — glyph PBFs for the Protomaps basemap style (Noto Sans Regular/Medium/Italic,
  Noto Sans Devanagari Regular). Licensed under the [SIL Open Font License](fonts/OFL.txt).
- `sprites/v4/` — spritesheets for the Protomaps basemap style. Derived from
  [MIT-licensed tangrams/icons](https://github.com/tangrams/icons/blob/master/LICENSE.md).

Neither directory is modified from upstream. Re-download from the source repo to update.
